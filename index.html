🔷 Função Hash (SHA-256)
O Hash é uma "impressão digital" de um dado. Qualquer mudança na entrada gera um hash completamente diferente. É uma função de via única: não é possível voltar do hash para o dado original.

📦 Bloco com mineração
Um bloco contém índice, nonce, dados e hash. O hash é calculado sobre esses campos + hash anterior. Mineração: encontrar nonce que faça o hash começar com "0000" (dificuldade 4).

⛓️ Cadeia de blocos
Blockchain é uma lista onde cada bloco contém o hash do anterior. Para ser válido, cada bloco deve ter um hash que comece com "0000" (minerado). Editar um bloco quebra a corrente; é necessário minerá-lo novamente.

🌐 Rede distribuída (3 nós independentes)
Cada nó possui sua própria blockchain. Você pode adicionar blocos e minerá‑los separadamente. O botão Sincronizar rede encontra a cadeia mais longa totalmente válida (todos os blocos minerados com "0000" e encadeados) e a copia para todos os nós.
